# 📊 Mobile Sales Analysis Dashboard – Power BI

## 📌 Project Overview
This project presents an interactive **Mobile Sales Analysis Dashboard** developed using Microsoft Power BI. The dashboard provides valuable insights into mobile sales performance, customer ratings, payment preferences, and brand-wise sales trends.

The main objective is to transform sales data into meaningful business insights through interactive visualizations and data analysis.

## 🎯 Key Features
- **KPI Cards:** Total Sales, Total Quantity, and Total Transactions.
- **City-wise Sales:** Geographical analysis of sales across different cities.
- **Monthly Trends:** Monthly analysis of sales quantity.
- **Customer Ratings:** Analysis of customer satisfaction ratings.
- **Payment Methods:** Transaction distribution across UPI, Debit Card, Credit Card, and Cash.
- **Brand Analysis:** Comparison of mobile brands based on sales and quantity.
- **Mobile Model Analysis:** Sales performance of different mobile models.
- **Day-wise Sales:** Analysis of sales across different days of the week.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Interactive Dashboards
- Business Intelligence

## 📊 Dashboard Insights
The dashboard helps users:
- Monitor overall mobile sales performance.
- Identify top-performing cities and mobile brands.
- Understand customer payment preferences.
- Analyze monthly and day-wise sales trends.
- Evaluate customer satisfaction through ratings.
